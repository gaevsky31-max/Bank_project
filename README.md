# Bank Operations Widget

Проект для обработки и анализа банковских операций клиента. Включает функции для фильтрации, сортировки и форматирования банковских операций.

## Цель проекта

Создание системы для удобной работы с банковскими операциями: фильтрация по статусу, сортировка по дате, маскирование номеров карт и счетов, форматирование дат.

## Структура проекта

## Декоратор log

### Описание
Модуль `src/decorators.py` содержит декоратор `log` для автоматического логирования вызовов функций.

### Функциональность
- Логирование успешного выполнения функций (результат, время выполнения)
- Логирование ошибок (тип ошибки, входные параметры)
- Вывод логов в консоль или в файл
- Сохранение метаданных оригинальной функции

### Использование

```python
from src.decorators import log

# Логирование в консоль
@log()
def my_function(x, y):
    return x + y

# Логирование в файл
@log(filename="app.log")
def another_function(data):
    return process(data)
